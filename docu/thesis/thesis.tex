\section*{Disclosure of the use of generative AI}

In the writing of this thesis, various generative AI tools were used in accordance to the KIT's guidelines on the use of generative AI~\cite{KIT_GenerativeKI_Leitfaden_2024}. The GPT-5.2 model and DeepL were used for proofreading and improving the language of the thesis. The use of these tools is limited to these purposes, while all scientific content and ideas were developed by the author independently. The author has critically reviewed and edited all content modified by these tools to ensure accuracy.

For assistance in the implementation of the algorithms presented in this thesis GitHub Copilot with the Claude Sonnet 4.5 model was used. This assistance was limited to small code suggestions and partial generation of documentation. The design of the algorithms, the general code structure and architecture and all scientific content were developed by the author independently.
