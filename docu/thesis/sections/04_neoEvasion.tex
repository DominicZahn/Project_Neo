\section{Neo} \label{sec:neo}
In the last section we identified a major shortcoming of our \textit{neo} method.
As the dodge constraint \cref{eq:neo:constraints:dodge} limits solely the last pose of the motion, the approaching object could collide in the time before with the robot, for example during a swing up torso move.
\\
Another problem pose approaching object with a stepper angle.
Those objects can not be avoided by robot ducking underneath a certain height, as the exact end pose and positioning of the body is important.
\\
Using the exact distance between object and robot body also enable the solver to find minimal evasion motions, where the robot perturbs away from the object, without the need for spacious and unstable moves.
The next step is therefore to improve our previous formulation, to form a descendant called \textit{Neo}.
\par
At first we are tackling the challenge of computing the distance between robot and approaching object (\cref{sec:neo:distance}).
Afterwards the formulation is adjusted to better suit the changes made in the dodge constraint.
Like it was done for \textit{neo} we also conclude the \textit{Neo} method by analyzing a specific motion, before a full testing of the method is done in \cref{sec:eval}.

\subsection{Robot Object Distance} \label{sec:neo:distance}
The field of separation-distance calculation is closely tied to collision detection and avoidance.
To effectively plane motions for collision avoidance distance between objects must be computed \cite{toth_2017}.
Distance functions are an important tool in robotics and computer graphics to calculate object-to-object distances.
These functions define, for each point in space, the distance to the specified object \cite{jones_2006}.
\\
During the last decades multiple different solutions were developed.
One of them is the DCOL algorithm from Tracy et al. \cite{tracy_2023}.
They formulate a convex optimization problem with a conic constraint, that scales both objects until they create a minimal overlap.
The distance distance and the closest points to each other are computed by finding the overlap point on the respective object.
\begin{figure}
  \centering
  \includegraphics{figures/04_neoEvasion/tracy_scaled.pdf}
  \caption{
    The image shows the principle of the DCOL algorithm from Tracy et al. \cite{tracy_2023}.
  Both objects are scaled until they intersect to compute the closest points, while implicitly calculating the distance between them.
}
  \label{fig:neo:distance:tracy:scaled}
\end{figure}
\Cref{fig:neo:distance:tracy:scaled} displays and example of the computation for a cone and an polytope.
\\
To build a full motion planner around such methods leads to bi-level formulations, where two levels optimization need to be solved.
In every iteration of the motion generator, the lower level separation-distance problem has to be resolved, to provide this information to the higher-level.
\\
Jaitly et al. \cite{jaitly_2025} formulate a single level solution, by presenting a "Minimum-Offset-To-Touch" (MOTT) condition.

\par
The difference to a \textit{signed} distance function is that it is negative inside the shape, while retaining positive values on the outside.
An inverse convention can also be found in some literature.
A \acrshort{sdf} functions easy to evaluate and compose properties show themselves when used in path-planning for robotic arms \cite{zhu_2025}, autonomous navigation of \acrshort{uav}s \cite{jacquet_2025} or dexterous manipulation \cite{yang_2025}. \\
Our work leverages a \acrshort{sdf} for the collision hull of our humanoid robot, it provides the distance between the robot and an approaching object $d(\bm{p}(t))$ for every point in time $t$.
The following section presents the collision model for the upper body of our H1-2
It is composed of ellipsoid-shaped collision primitives, which are fused together with a smooth transition function.

\subsubsection{Ellipsoid SDFs}

\begin{subequations}
  \label{eq:neo:distance:ellipsoid}
  \begin{align}
    k_0 &= \left\lVert \frac{\bm{p} - \bm{c}}{\bm r} \right\rVert_2 \\
    k_1 &= \left\lVert \frac{\bm{p} - \bm{c}}{\bm r^2} \right\rVert_2 \\
    d(\bm{p}) &= \frac{k_0 \cdot (k_0-1)}{k_1}
  \end{align}
\end{subequations}

\subsubsection{Smooth Transition Function}
In order to not only calculate the distance to a single object, but a whole set, a proximity graph, like the Voroni diagram, needs to be accessible.
To find the distance between a point in space and the shortest distance to a set of collision volumes this structure needs to be searched \cite{toth_2017}.
\begin{figure}
  \centering
  \begin{subfigure}[b]{0.45\textwidth}
    \includegraphics[width=\textwidth]{figures/04_neoEvasion/collisionHull/primitives.png}
    \caption{individual primitives}
    \label{fig:neo:distance:primitives}
  \end{subfigure}
  \hfill
  \begin{subfigure}[b]{0.45\textwidth}
    \includegraphics[width=\textwidth]{figures/04_neoEvasion/collisionHull/composition.png}
    \caption{composed collision hull}
    \label{fig:neo:distance:composed}
  \end{subfigure}
  \caption{
  (a) visualizes the individual ellipsoid collision primitives, which are combined by leveraging the smooth transition function (\cref{eq:neo:distance:smin}) to a composition in (b).
  }
  \label{fig:neo:distance}
\end{figure}
Especially for volumes like the ones displayed in \cref{fig:neo:distance:primitives}, where multiple collision primitives are merged to provide a single collision hull, \acrshort{sdf}s are able to solve that problem, by utilizing transition functions.
\par
One of those is the sigmoid function
\begin{equation}
\text{smin}_k(d_i,d_j) = d_i+\frac{d_j-d_i}{1-e^{\frac{d_j-d_i}{k\log 2}}} = d_\text{union} \label{eq:neo:distance:smin},
\end{equation}
which was proposed by Quilez for fusing multiple \acrshort{sdf}s to a single surface \cite{sdfSmoothMin}.
\begin{figure}
  \centering
  \includegraphics[width=0.5\textwidth]{figures/04_neoEvasion/surferBoy.png}
  \caption{
    The application of \cref{eq:neo:distance:smin} to render a face composed of multiple different shapes.
    The illustration was taken from Quilez \cite{sdfSmoothMin}.
  }
  \label{fig:neo:sdf:face}
\end{figure}
He used this technique to blend different shapes together to smoothly rendered face, which can be seen in \cref{fig:neo:sdf:face}.
\\
This property to blend shapes, described by \acrshort{sdf}s into each other is can be defined by the smoothing factor $k$ in \cref{eq:neo:distance:smin}.
As we are step-by-step concatenating primitives together, we also would be able to set individual smoothing factors at each connection.
The result is a human like skin, that spans from one ellipsoid to another, generating a continuous collision hull. \\
As each of the ellipsoids is anchored to a local frame of the robot, the connections between them adapt for each change in joint angle.
\par
For more complex robots or a higher-precision collision hull, an automatic generation would be possible.
John-Löwner Ellipsoids are a well-known solution for such problems \cite{john_1985}.
Other high-level methods have been found, like ellipsoid decompositions from meshes \cite{bischoff_kobbelt_2009} or optimization-based solutions \cite{elkhoury_2013a}.
